# User documentation

End-user docs for clojure-rs. Brother folder `../spec/` holds the
design specs, contracts, and oracle probes — contributor-facing
material. Keep this folder to prose a *user* of the port would read.

- [`clojure/pprint/`](clojure/pprint/) — upstream `clojure.pprint`
  user docs, vendored verbatim: `PrettyPrinting.markdown` (usage)
  and `CommonLispFormat.markdown` (format directives).
